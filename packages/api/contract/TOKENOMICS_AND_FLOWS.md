# Skyhitz Tokenomics V2 - Post-Exhaustion Model

## 🎯 Executive Summary

The Skyhitz platform operates in **post-exhaustion mode** with the HITZ token supply fully issued (~20M of 21M max). The system uses a sustainable distribution model inspired by Bitcoin's emission curve.

## 📊 HITZ Token Economics

### Current State

| Parameter | Value |
|-----------|-------|
| **Max Supply** | 21,000,000 HITZ |

### Post-Exhaustion Distribution

Instead of minting new tokens, rewards come from treasury distribution:

```
Treasury Balance → 0.05% daily → Entry Reward Pools → Stakers
```

**12-Year Emission Curve**:
| Year | Treasury Distributed | Cumulative |
|------|---------------------|------------|
| 1 | ~17% | 17% |
| 4 | ~35% | 52% |
| 8 | ~25% | 77% |
| 12 | ~11% | 88% |

This matches Bitcoin's proven halving model, ensuring sustainable rewards for 12+ years.

### Staking Model (1:1 Ratio)

**Post-exhaustion simplification**: Fee = Stake

```
Stake Amount = Fee Paid
```

- No oracle dependency
- No price manipulation risk
- Simple and predictable

**Example**:
- Mine action: Pay 1 HITZ fee → Stake 1 HITZ
- Invest 10 HITZ: Pay 10 HITZ fee → Stake 10 HITZ

## 💰 Dual Revenue Stream Model

### 1. Escrow (Non-Equity Revenue)
- **Generated by**: stream, like, download
- **Destination**: Treasury wallet
- **Purpose**: Performance-based metric for distribution
- **Effect**: Entry's `escrow` increases

### 2. TVL (Total Value Locked - Equity Revenue)
- **Generated by**: mine, invest
- **Destination**: Contract (stake)
- **Purpose**: Entry valuation and ownership
- **Effect**: Entry's `tvl` and `total_stake` increase

## 🔄 Complete Flow Diagrams

### Flow 1: Non-Staking Action (Stream/Like/Download)

```
┌─────────┐
│  User   │ Streams a song
└────┬────┘
     │
     │ 1. Pay 0.1 HITZ fee
     ▼
┌─────────────────┐
│ Skyhitz Core    │
│ record_action() │
└────┬───────────┘
     │
     │ 2. Transfer HITZ fee to Treasury
     ▼
┌──────────────┐
│   Treasury   │ Collects fees for distribution
└──────────────┘
     │
     │ 3. Entry.escrow += 0.1 HITZ
     │
     │ NOTE: No minting - user just pays fee
     ▼
┌─────────┐
│  Done   │ Entry escrow increased
└─────────┘
```

**Result**: User pays 0.1 HITZ; entry's escrow increases for future distribution allocation.

### Flow 2: Staking Action (Mine/Invest)

```
┌─────────┐
│  User   │ Mines song (1 HITZ)
└────┬────┘
     │
     │ 1. Pay 1.0 HITZ (fee = stake)
     ▼
┌─────────────────┐
│ Skyhitz Core    │
│ record_action() │
└────┬───────────┘
     │
     │ 2. Transfer 1 HITZ to Contract
     │    (becomes user's stake)
     │
     │ 3. Record stake:
     │    stakes[user][entry] += 1 HITZ
     │    entry.total_stake += 1 HITZ
     │    entry.tvl += 1 HITZ
     │
     │ NOTE: No minting - stake IS the fee
     ▼
┌─────────┐
│  Done   │ User now owns stake in entry
└─────────┘
```

**Result**:
- User pays 1 HITZ as stake
- User owns % of entry based on stake
- User can claim rewards from entry pool
- User can unstake later

### Flow 3: Treasury Distribution (Daily)

```
┌──────────────┐
│ Treasury Bot │ Runs daily
└──────┬───────┘
       │
       │ 1. Calculate 0.05% of treasury balance
       │    (Bitcoin-like rate limiting)
       │
       │ 2. Call distribute_rewards()
       ▼
┌─────────────────────┐
│ Skyhitz Core        │
│ distribute_rewards()│
└──┬────────┬────┬───┘
   │        │    │
   │ 3. Transfer HITZ from Treasury to Contract
   │
   │ 4. Calculate total escrow:
   │    total = sum(all entry.escrow)
   │
   │ 5. For each entry with escrow > 0:
   │    share = (entry.escrow / total) × hitz_amount
   │    entry.reward_pool += share
   │
   ▼        ▼    ▼
Entry A  Entry B  Entry C
+share   +share   +share
```

**Key Points**:
- Only 0.05% of treasury distributed per day
- Distribution proportional to escrow (engagement)
- Creates 12+ year sustainable runway
- Prevents market flooding

### Flow 4: Staker Claims Rewards

```
┌─────────┐
│ Staker  │ Has 50 HITZ staked (25% of total)
└────┬────┘
     │
     │ 1. Call claim_rewards()
     ▼
┌─────────────────┐
│ Skyhitz Core    │
│ claim_rewards() │
└─────┬───────────┘
      │
      │ 2. Calculate staker pool:
      │    - If artist equity exists:
      │      staker_pool = pool × (100% - artist_equity%)
      │    - Otherwise: staker_pool = pool
      │
      │ 3. Calculate claimable:
      │    share = (user_stake / total_stake) × staker_pool
      │    claimable = share - already_claimed
      │
      │ 4. Update claimed record
      │
      │ 5. Transfer HITZ to user
      ▼
  ┌─────────┐
  │ Staker  │ Receives claimed HITZ
  └─────────┘
```

### Flow 5: Artist Claims Equity

```
┌─────────┐
│ Artist  │ Has 20% equity (2000 bps)
└────┬────┘
     │
     │ 1. Call claim_artist_equity()
     ▼
┌──────────────────────┐
│ Skyhitz Core         │
│ claim_artist_equity()│
└─────┬────────────────┘
      │
      │ 2. Calculate artist share:
      │    share = reward_pool × (equity_bps / 10000)
      │    claimable = share - already_claimed
      │
      │ 3. Update claimed record
      │
      │ 4. Transfer HITZ to artist
      ▼
  ┌─────────┐
  │ Artist  │ Receives 20% of pool growth
  └─────────┘
```

### Flow 6: Unstaking

```
┌─────────┐
│  User   │ Wants to withdraw 50 HITZ stake
└────┬────┘
     │
     │ 1. Call unstake(entry_id, amount)
     ▼
┌─────────────────┐
│ Skyhitz Core    │
│ unstake()       │
└─────┬───────────┘
      │
      │ 2. Verify user has enough stake
      │
      │ 3. Update stakes:
      │    stakes[user][entry] -= 50
      │    entry.total_stake -= 50
      │
      │ 4. Transfer 50 HITZ back to user
      ▼
  ┌─────────┐
  │  User   │ Receives 50 HITZ
  └─────────┘
```

## 📈 APR Calculation

### Formula

```
APR = ((reward_pool / total_stake) / days_since_creation) × 365 × 10000
```

Returns APR in **basis points** (1% = 100, 10% = 1000)

### Example

| Parameter | Value |
|-----------|-------|
| Entry created | 30 days ago |
| Total stake | 500 HITZ |
| Reward pool | 100 HITZ |

**Calculation**:
```
Daily return = 100 / 500 = 0.2 = 20%
Daily rate = 20% / 30 days = 0.667% per day
Annual rate = 0.667% × 365 = 243.3%
APR = 24,330 basis points
```
