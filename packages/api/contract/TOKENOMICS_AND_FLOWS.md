# Skyhitz Tokenomics & Flow Analysis

## 🎯 Executive Summary

The Skyhitz platform uses a dual-contract system with **HITZ** token and **Skyhitz Core** contract to create a sustainable music economy with Bitcoin-style emission schedule.

## 📊 HITZ Token Economics

### Supply Model

| Parameter | Value |
|-----------|-------|
| **Max Supply** | 21,000,000 HITZ |
| **Decimals** | 7 (210,000,000,000,000 stroops) |
| **Pre-mint** | 0 (all tokens released through rewards) |
| **Distribution** | On-demand via user actions |

### Emission Schedule (Bitcoin-style Halving)

```
Epoch 0: 0.3000000 HITZ per unit (Years 0-4)
Epoch 1: 0.1500000 HITZ per unit (Years 4-8)
Epoch 2: 0.0750000 HITZ per unit (Years 8-12)
Epoch 3: 0.0375000 HITZ per unit (Years 12-16)
...continues until epoch 64 (~256 years)
```

**Halving Interval**: 126,144,000 seconds (exactly 4 years)

### Emission Timeline Projection

| Year | Epoch | Unit Reward (HITZ) | Approx. Total Released |
|------|-------|-------------------|----------------------|
| 0-4 | 0 | 0.3 | ~10.5M HITZ |
| 4-8 | 1 | 0.15 | ~15.75M HITZ |
| 8-12 | 2 | 0.075 | ~18.375M HITZ |
| 12-16 | 3 | 0.0375 | ~19.6875M HITZ |
| 16-20 | 4 | 0.01875 | ~20.34M HITZ |
| 20-24 | 5 | 0.009375 | ~20.67M HITZ |
| 24+ | 6+ | <0.005 | Approaches 21M |

**Note**: ~99% of supply released in first 24 years, similar to Bitcoin's emission curve.

## 🎵 User Action System

### Action Types & Rewards

| Action | Difficulty | Default Fee | HITZ Reward (Epoch 0) | Stake Required | TVL/Escrow |
|--------|-----------|-------------|---------------------|----------------|------------|
| **Stream** | 1 | 0.1 XLM | 0.3 HITZ | No | Escrow |
| **Like** | 2 | 0.2 XLM | 0.6 HITZ | No | Escrow |
| **Download** | 3 | 0.3 XLM | 0.9 HITZ | No | Escrow |
| **Mine** | 10 | 1.0 XLM | 3.0 HITZ | Yes (50 HITZ) | TVL |
| **Invest** | 10-1000+ | 0.3-100+ XLM | 3.0-300+ HITZ | Yes (variable) | TVL |

### Invest Action (Dynamic)

- **Minimum**: 0.3 XLM → 3 difficulty → 0.9 HITZ reward
- **Scaling**: 10 difficulty units per 1 XLM
- **Example**: 1 XLM → 10 difficulty → 3.0 HITZ reward + 500 HITZ stake
- **Example**: 10 XLM → 100 difficulty → 30 HITZ reward + 5,000 HITZ stake

### Stake Requirements

**Stake Unit**: 5 HITZ (50,000,000 stroops) per difficulty unit

| Action | Difficulty | Stake Required |
|--------|-----------|----------------|
| Mine | 10 | 50 HITZ |
| Invest (0.3 XLM) | 3 | 15 HITZ |
| Invest (1 XLM) | 10 | 50 HITZ |
| Invest (10 XLM) | 100 | 500 HITZ |

## 💰 Dual Revenue Stream Model

### 1. Escrow (Non-Equity Revenue)
- Generated by: **stream, like, download**
- Purpose: Performance-based revenue
- Distribution: Converted to HITZ via Treasury bot → allocated to reward pools

### 2. TVL (Total Value Locked - Equity Revenue)
- Generated by: **mine, invest**
- Purpose: Entry valuation and long-term investment
- Distribution: Proportional ownership stake

### Flow 3: Treasury Bot → Core Contract Distribution

```
┌──────────────┐
│ Treasury Bot │ Runs periodically
└──────┬───────┘
       │
       │ 1. Collect accumulated XLM fees
       │
       │ 2. Buy HITZ with XLM
       │    (on Stellar DEX)
       ▼
┌──────────────┐
│  HITZ Token  │
└──────┬───────┘
       │
       │ 3. Send all HITZ to Core contract
       │    distribute_rewards(1000 HITZ)
       ▼
┌─────────────────────┐
│ Skyhitz Core        │
│ distribute_rewards()│
└──┬────────┬────┬────┘
   │        │    │
   │ 4. Core calculates distribution
   │    based on escrow_xlm performance:
   │    - Entry A: 500 escrow → 50%
   │    - Entry B: 300 escrow → 30%
   │    - Entry C: 200 escrow → 20%
   │
   │ 5. Automatically allocates to pools
   ▼        ▼    ▼
Entry A  Entry B  Entry C
+500     +300     +200
HITZ     HITZ     HITZ
```

**Key Point**: Treasury bot doesn't need to know about entry performance—the Core contract handles the distribution logic automatically!

### Flow 4: Staker Claims Rewards

```
┌─────────┐
│ Staker  │ Has 50 HITZ staked (25% of total)
└────┬────┘
     │
     │ 1. Request claim
     ▼
┌─────────────────┐
│ Skyhitz Core    │
│ claim_rewards() │
└─────┬───────────┘
      │
      │ 2. Calculate claimable:
      │    Pool: 100 HITZ
      │    User stake: 50 / 200 total = 25%
      │    Claimable: 100 × 0.25 = 25 HITZ
      │    Already claimed: 0
      │    To claim: 25 HITZ
      │
      │ 3. Update claimed record
      │
      │ 4. Transfer HITZ from contract
      ▼
  ┌─────────┐
  │ Staker  │ Receives 25 HITZ
  └─────────┘

  Future claims:
  - Pool grows to 200 HITZ
  - User's share: 200 × 0.25 = 50 HITZ
  - Already claimed: 25 HITZ
  - Next claim: 25 HITZ
```

## 📈 APR Calculation

### Formula

```
APR = ((reward_pool / total_stake) / days_since_creation) × 365 × 10000
```

Returns APR in **basis points** (1% = 100, 10% = 1000)

### Example Scenario

| Parameter | Value |
|-----------|-------|
| Entry created | 30 days ago |
| Total stake | 500 HITZ |
| Reward pool | 100 HITZ |

**Calculation:**
```
Daily return = (100 / 500) = 0.2 = 20%
Daily rate per unit = 20% / 30 days = 0.667% per day
Annual rate = 0.667% × 365 = 243.3%
Basis points = 243.3 × 100 = 24,333
```

**Result: 243.3% APR**

### APR Scenarios

| Pool Size | Total Stake | Days Elapsed | APR (%) |
|-----------|-------------|--------------|---------|
| 100 HITZ | 500 HITZ | 30 | 243% |
| 500 HITZ | 2000 HITZ | 60 | 152% |
| 1000 HITZ | 5000 HITZ | 90 | 162% |
| 50 HITZ | 1000 HITZ | 7 | 260% |

**Note**: APR is highly variable based on:
- Treasury bot allocation frequency
- Entry's escrow performance
- Total stake competition
- Time since creation

## 🎯 Economic Incentives

### For Users

1. **Listeners** (Stream/Like/Download)
   - Pay small fees (0.1-0.3 XLM)
   - Earn HITZ rewards immediately
   - No stake required

2. **Miners** (Mine action)
   - Pay 1 XLM + stake 50 HITZ
   - Earn 3.0 HITZ rewards
   - Get equity stake in entry
   - Receive proportional revenue share

3. **Investors** (Invest action)
   - Pay 0.3+ XLM + stake proportional HITZ
   - Earn HITZ rewards proportional to investment
   - Get larger equity stake
   - Higher potential returns

### For Artists/Entry Owners

1. **Escrow Revenue**
   - Earn from streams, likes, downloads
   - Converted to HITZ by Treasury
   - Distributed to stakers

2. **TVL Growth**
   - Entry valuation increases with investments
   - Attracts more investors
   - Higher entry ranking

### For the Ecosystem

1. **HITZ Token**
   - Scarce supply (21M cap)
   - Deflationary issuance (halving)
   - Utility: staking, governance, rewards

2. **XLM Economy**
   - All fees in XLM
   - Treasury provides liquidity
   - Market-making on DEX

## 🚀 Economic Sustainability

### Short-term (Years 0-4)
- High emission rate (0.3 HITZ per unit)
- Attracts early users and investors
- Builds initial liquidity
- Establishes entry valuations

### Mid-term (Years 4-12)
- Emission halves twice (0.15 → 0.075 HITZ)
- Scarcity increases HITZ value
- Established market dynamics
- Mature staking ecosystem

### Long-term (Years 12+)
- Minimal new emission (<0.0375 HITZ)
- HITZ becomes scarce asset
- Reward pools sustained by secondary market
- Ecosystem fully self-sustaining
